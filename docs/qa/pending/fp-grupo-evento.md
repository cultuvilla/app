# Un evento de grupo se abre desde el grupo y desde el pueblo

**Preparación:** Admin de un grupo con un evento (crea uno con el grupo como organizador si no hay).

**Pasos:**
1. Grupo → eventos → ábrelo.
2. El mismo evento desde Mi pueblo.

**Esperado:** Las dos rutas muestran el mismo evento, con el grupo como organizador.

**Roto se ve así:** Una de las dos rutas da no encontrado o datos distintos.
